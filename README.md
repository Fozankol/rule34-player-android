## ✨ Ключевые возможности

### ⏱️ 1. Фильтрация видео по длительности
На сайтах Rule34 нет фильтра по длине ролика. Наше приложение решает эту проблему:
* Пресеты в один клик: **`> 2 мин`**, **`> 5 мин`**, **`> 10 мин`**, **`Все`**.
* Точный ползунок выбора минимальной длительности (от 30 сек до 60 мин).
* **Серверлесс HTTP Range Probing**: клиент считывает только первые 128 КБ заголовков контейнеров (`moov`/`mvhd` для MP4 и EBML для WebM), определяя точную длину видео за доли секунды без траты трафика.
* Все полученные длительности кэшируются в локальную базу данных **SQLite**.

### ⚡ 2. Мгновенный свайп без буферизации (N+1 Pre-buffering)
* Полноэкранный плеер в стиле вертикальных Reels / TikTok.
* Следующее видео в ленте предзагружается в буфер заранее. При свайпе вверх ролик начинает воспроизводиться **мгновенно, без задержек и спиннеров**.
* Автоматическая очистка контроллеров из памяти для плавной работы даже на слабых устройствах.

### 🚀 3. Глубокая авто-подгрузка (Deep Auto-Pagination)
* При строгих фильтрах (`> 10 мин`) редкие видео больше не требуют многократной ручной прокрутки вниз.
* Приложение в фоновом режиме параллельно опрашивает страницы каталога и видео-контейнеры, автоматически собирая полную пачку подходящих роликов (15–20 видео).
* Прямо в ленте виден прогресс сканирования в реальном времени.

### 🌐 4. Поддержка Realbooru & Мульти-источники
* **Realbooru.com**: встроенный парсер с обходом hotlink-защиты (`Referer`). Работает **сразу без API-ключа**!
* **Rule34.xxx**: основной каталог с поддержкой персонального API-ключа.
* **TBIB & Safebooru**: альтернативные booru-каталоги.

### 🖼️ 5. Просмотр фото и артов высокого качества
* Удобный переключатель в шапке: **`Все` | `Видео` | `Фото`**.
* Полноэкранная галерея с плавным pinch-to-zoom (`InteractiveViewer`), свайпом, просмотром тегов автора и сохранением в избранное.

### ❤️ 6. Рейтинг и лайки (Score)
* Фильтр по минимальному количеству лайков: **50+**, **100+**, **500+**.
* Сортировка по популярности, дате добавления или длине видео.

### 📥 7. Загрузка и Избранное
* Сохранение видео и фото прямо в память устройства в высоком качестве.
* Локальные закладки с разделением по категориям (Все / Видео / Фото).

### 🛡️ 8. Приватность и обход блокировок
* Встроенная поддержка **DNS-over-HTTPS (DoH)** через Cloudflare (1.1.1.1) и Google (8.8.8.8) для стабильной работы при блокировках провайдеров.
* Локальный **Черный список (Blacklist)** тегов.

## 🛠️ Сборка из исходников (Build from Source)

Требования:
* **Flutter SDK**: 3.24+ (рекомендуется 3.47+)
* **JDK**: 17+
* **Android SDK**: API 34+ / 36

```bash
# 1. Клонировать репозиторий
git clone https://github.com/<username>/rule34-player-android.git
cd rule34-player-android

# 2. Установить зависимости
flutter pub get

# 3. Собрать релизный APK
flutter build apk --release
```
Готовый файл появится по пути: `build/app/outputs/flutter-apk/app-release.apk`.

## 🔑 Авторизация Rule34.xxx
Сайт Rule34.xxx требует бесплатный персональный ключ API:
1. Зарегистрируйтесь на сайте [rule34.xxx](https://rule34.xxx).
2. Перейдите в **Account -> Options**.
3. Скопируйте **User ID** и **API Key**.
4. Вставьте их в приложении во вкладке **Настройки**.
*(Или просто переключите источник на **Realbooru** или **TBIB**, где ключ не требуется!)*
